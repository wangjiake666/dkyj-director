# 场内分镜使用说明

同一场戏的所有分镜共享人物走位与动作时间轴。切换的是机位和镜头时长，人物动作不会从头重播。

## 添加与调整

1. 打开场次，在手机或手柄取景中找到角度，停止录制后，展开网页底部「场内分镜」。
2. 点击添加当前机位，填写名称与时长。默认保存静态角度；下一镜紧接上一镜。
3. 换一个取景角度，再添加下一镜。已有分镜可修改名称、时长、替换角度或删除。
4. 点击连续预览查看整场，再点击保存场次，保留修改。

所有镜头不能超过该场次原时长；每场最多 40 镜。录制与导出过程中暂停编辑。只添加镜头不会复制人物或改变原有动作关键帧。

默认分镜是静态机位。勾选「沿用已录制运镜」可复制已录制机位的运动，但仍沿用原始帧号，不自动重新配速。替换角度会将该分镜改为当前静态机位。

## 导出

选择镜头 16:9、空间 16:9 或双画面参考套件，再点击「导出本场分镜」。镜头和俯视图共用切点与人物时间轴；双画面套件包含独立画面及上下合并视频，每一路画面各为 16:9。下载附带的分镜 JSON 可查看时长与机位。

场次的工程打包会保留分镜与正面颜色设置，换电脑后导入工程即可继续编辑。切换电脑仍需安装 Blender、Python 与客户端依赖。

## 正面朝向颜色

在场内分镜区域切换「正面朝向颜色」。适用于无四肢简模：球形头部和方块身体，只改变正面材质颜色，开关不会增加几何或修改人物走位。旧详细角色和无法识别的模型保持原样。

## 手柄与预览

Xbox 为默认映射，可切换 PS5 标准映射。分别调整移动／升降与转向灵敏度，设置会保存。电脑 Mac 使用 Safari、Windows 使用 Edge；手机只支持 iPhone Safari。PS5、iPhone 和 Windows 本轮尚未完成实机验收。
